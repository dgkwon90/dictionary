# 목적

- mac os, windows os 공통으로 시스템 단축키를 통해 빠르게 영어 문장 및 영어 단어를 검색할 수 있도록 한다.
- 검색 결과는 바로 확인할 수 있으며, 다른 창 또는 검색 중이 화면에서 포커스가 벗어나거나 꺼져도 검색 결과는 알림을 통해 검색 결과를 확인 할 수 있다.
- 단어를 검색했을 경우는 단어에 대해 모르기 때문에 문의 했다고 판단한다.
- 문장을 검색했을 경우는 문장 안에 모르는 단어가 있을 수 있다고 가정하고 문의 했다고 판단한다.
- 검색 했던 기록 및 결과를 이력으로 남긴다.
- 검색 이력에는 기본적으로 모든 검색 기록을 볼수 있지만, 처음에는 미확인한 검색만 표시되고, 원할떄 전체를 볼 수 있도록 한다.
- 각 검색 기록을 누르면 그에 대한 결과를 확인할 수 있다.
- 단어의 경우는 모르는 단어, 즉 학습이 필요한 단어로 바로 구분하도록 한다.
- 문장의 경우는 검색 결과를 눌렀을 때, 문장 안에서 모르는 단어를 선택하도록 한다. 만약, 모르는 단어를 아직 선택하지 않았다면, 아직 문장을 왜 몰랐는지 제대로 파악하지 못한 것으로 간주하고, 모르는 단어를 선택할 수 있는 상태로 둔다.
- 문장에서 모르는 단어를 선택하면 그 단어에 대해 다시 한번 설명하며, 모든 단어를 선택하고 완료를 누르면, 선택한 단어들을 모른 단어, 즉 학습이 필요한 단어로 구분하도록 한다. 문장의 상태는 왜 몰랐는지 파악이 완료된 상태로 변경한다.
- 단어 검색 결과 확인이 되면 모르는 단어로, 문장 검색 결과에서도 모르는 단어까지 확인이 되면 모르는 문장으로 전환된다.
- 전환된 모르는 단어는 학습이 필요한 단어로 전환되서, 학습 목록에 추가되도록 한다.
- 전환된 모르는 문장은 학습이 필요한 문장으로 전환되서, 학습 목록에 추가되도록 한다.
- 전환된 모르는 문장에서 선택한 모르는 단어도 학습이 필요한 단어로 추가된다.
- 학습 필요 한 단어를 학습 목록에서 확인 할 수 있어야한다.
- 학습 필요 한 문장을 학습 목록에서 확인 할 수 있어야한다.
- 사용자가 같은 단어를 중복해서 검색 및 모르는 단어로 선택 했다면, 학습 목록에 추가되지는 않지만 얼마나 자주 모르는 단어로 선택했는지 횟수를 기록해둔다.
- 학습 목록에 있는 단어를 기반으로 연습할 수 있도록 한다. 하나 선택할 수 도 있고, 오늘 등록한 단어만 선택할 수도 있고, 이번 주에 등록한 단어만 선택할 수도 있다. 추가로 자주 틀렸던 단어 위주로 연습을 할 수도 있다.
- 학습 목록에 있는 문장을 기반으로 연습을 할 수 잇도록 한다. 오늘 등록한 문장만 선택할 수도 있고, 이번 주에 등록한 문장만 선택할 수도 있다. 추가로 자주 틀렸던 문장 위주로 연습을 할 수도 있다.
- 학습 목록에 대해서 연습 및 복습 횟수와 결과를 저장하며, 정답률을 기록한다.
- 자동으로 복습하도록 하는 설정할 수 있으며, 복습 주기를 설정할 수 있다.
- 정답률이 100%인 단어 또는 문장은 복습 목록에서 제외하거나, 복습 우선순위를 낮춘다.
- 학습 기록을 기록 내보내기, 기록 가져오기를 통해 백업 및 복원이 가능하다.
- 검색은 gemini api 를 이용한다.
- gemini api key 는 환경 변수를 통해 설정한다.
- gemini 검색 요청시 원하는 답변 포맷을 지정할 수 있다. json 포맷을 권장한다.
- 답변 포맷에 따른 샘플을 제공한다. 포맷을 변경하지 않으면 기본값을 사용한다.
